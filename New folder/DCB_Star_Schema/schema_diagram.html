DCB Star Schema

Holenarasipura Division's Demand–Collection–Balance report, modeled as a star schema in dcb_star_schema.sqlite. Two fact tables share three dimensions — one dimension, dim_tariff_category, only ever joins to fact_dcb, since a rollup row spans more than one tariff category by definition.

  • 11 fiscal years
  • 8 sub-divisions
  • 139 tariff categories
  • 5,488 fact_dcb rows
  • 2,232 rollup rows
  • 0.0% reconciliation deviation
foreign key (many → one) view, derived from QA comparison, not a join

The 77 measure columns, grouped

Both fact tables carry the identical set of 77 numeric columns — the DCB arithmetic chain (Opening Balance → Demand → Collection → Closing Balance), each broken into Revenue / Interest / Tax / FAC sub-components, plus a P&G Surcharge component that only exists from fiscal year 2025-26 onward.
